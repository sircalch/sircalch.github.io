Ostrin

Lenguaje experimental de computación científica de Andrés Monreal.

Un lenguaje de programación construido desde primeros principios.

Ostrin es un proyecto experimental de lenguaje de programación para computación científica. Está implementado en Rust y reúne sintaxis, ejemplos, pruebas y herramientas de release en un proyecto de código abierto.

¿Por qué Ostrin?

El trabajo científico depende de cómo se representan, calculan y comparten las ideas. Ostrin explora el diseño de lenguajes como un espacio donde pueden encontrarse el razonamiento numérico, la reproducibilidad y las herramientas de desarrollo.

Principios de diseño

  • Partir de conceptos claros de lenguaje y computación.
  • Mantener los ejemplos cerca de la implementación.
  • Hacer inspeccionables los releases y los inventarios de pruebas.
  • Explorar ideas de computación científica sin presentar un sistema en desarrollo como una solución terminada.

Lo que funciona actualmente

  • Implementación pública en Rust con código fuente y ejemplos públicos.
  • Licencia MIT y release pública v0.1.0.
  • Inventario de pruebas de la release estable y un inventario separado de desarrollo.
  • Documentación pública, historial del repositorio y artefactos de release.

Lenguaje y tooling

El repositorio público describe Ostrin como un compilador e intérprete de validación de diseño para computación científica. Su dirección documentada incluye:

  • cantidades físicas como tipos, con comprobaciones dimensionales antes de ejecutar;
  • estado inmutable por defecto, registros, enumeraciones, genéricos, traits y pattern matching;
  • un compilador, checker e intérprete implementados en Rust;
  • scheduling cooperativo determinista con soporte opcional para hilos nativos;
  • diagnósticos JSON Lines e índices del compilador para tooling de editores;
  • tooling LSP y debug adapter, además de una extensión para VS Code;
  • un backend nativo experimental a C y un workflow reproducible de release para WASI.

Estas son capacidades y descripciones reportadas por el repositorio público. No son validación científica independiente, afirmaciones de preparación para producción ni resultados de benchmark. Consulta el README de Ostrin y la documentación de diseño como registro técnico canónico.
