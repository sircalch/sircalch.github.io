Herramientas de ciencia

Simuladores de uso libre y lecturas para explorar cómo medimos, analizamos y comunicamos resultados.

Simuladores

  • Laboratorio de medición — Explora cómo el sesgo y el ruido cambian una serie de mediciones.
  • Laboratorio de correlación — Compara lo que dicen los datos por grupo y lo que muestra el conjunto.

Notas de divulgación

  • ¿Qué significa medir bien? — Un ejemplo para distinguir cercanía a una referencia y dispersión de resultados.
  • Una correlación puede cambiar al juntar grupos — Un ejemplo para ver qué información pierde una gráfica cuando olvida el contexto.
  • Cómo documentar una figura que otros puedan repetir — Una forma de guardar los datos, decisiones y comandos que hay detrás de una gráfica.
  • Qué versión citar cuando usas software científico — Cómo dejar claro qué código produjo un resultado y facilitar que otros lo encuentren.

Casos y actividades

  • Caso reproducible de adsorción con AdsorpQC — Ejemplo ejecutable con una tabla de referencia pública del NIST.
  • Ejercicios de medición para Ingeniería Biomédica — Dos actividades para relacionar instrumentos, señales y mediciones de referencia.
