Caso reproducible de adsorción con AdsorpQC

Ejemplo ejecutable con una tabla de referencia pública del NIST.

Datos y procedimiento

El ejemplo usa la tabla del modelo de referencia de adsorción de CO₂ en ZSM-5 amoniacal del NIST a 293 K. La tabla contiene adsorción en exceso. Las presiones se mantienen en bar y los valores de mmol/g equivalen numéricamente a mol/kg. El código deja fuera cada quinto punto después de ordenar por presión.

Se ajustan cuatro modelos con 96 puntos y se calcula el error cuadrático medio, en su forma de raíz (RMSE), sobre 23 puntos de evaluación. Son puntos de la misma curva de referencia. El caso sirve para reproducir una comparación local dentro de su intervalo y no estima incertidumbre interlaboratorio.

Fuentes. NIST · Estudio interlaboratorio · Tabla en la revisión fijada.

Repite el cálculo

Descargar código Python · Descargar resultados y procedencia.

python -m pip install adsorpqc==1.2.0
python caso_nist.py

El código descarga la tabla en una revisión fija de ISODB y registra la huella SHA-256 del archivo que procesa. También acepta --input con una copia local de esa tabla. El resultado de referencia se calculó con NumPy 2.5.2 y SciPy 1.18.1.

Resultados del caso

  • Langmuir · 0.09912 mol/kg
  • Dual-Site Langmuir · 0.00945 mol/kg
  • Sips · 0.02757 mol/kg
  • Toth · 0.01512 mol/kg

El ajuste con menor AICc entre los cuatro en esta muestra fue Dual-Site Langmuir. Para trabajos nuevos, registra la versión de AdsorpQC y comprueba que las unidades y el tipo de adsorción correspondan a tus datos.
