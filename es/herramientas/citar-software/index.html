Generador de citas de software

Prepara un archivo CITATION.cff y una referencia para la versión que quieres citar.

Datos de la versión

Un autor por línea en el formato Apellidos, Nombres. Para un equipo usa Equipo: seguido de su nombre.

La fecha, el DOI y el repositorio son opcionales.

Vista previa

Completa los datos del software para generar los archivos.

Dónde dejar la cita

Guarda el archivo como CITATION.cff en la raíz del repositorio. GitHub puede mostrarlo en la opción para citar el repositorio. Usa el DOI de la versión ejecutada. Si solo tienes el enlace, incluye el repositorio y la versión.

El generador trabaja en tu navegador. Comprueba los metadatos en el depósito antes de publicar. Cómo elegir la versión que citas.
